1. Analiza
git status
git add README.md
git commit -m "Actualiza documentación"
git push
Explica qué ocurre en cada instrucción.

git status: Nos permite verificar que archivos han recibido algun tipo de modificación

git add README.md: Es un comando que indica que las modificaciones realizadas en README pueden
ir al stage para prepararse a ser enviados

git commit -m "Actualiza documentación": Con este comando podemos añadir una descripción sobre la modificación
que estamos haciendo, en este caso sería indicar que actualizamos la documentación

git push: Envía al repositorio en Git la modificación realizada con la descripción correspondiente
